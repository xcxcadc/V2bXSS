交互调整：

- 主菜单、协议、内核、TLS、添加下一个节点、配置修正均逐行显示数字；真实终端数字为绿色。
- 主菜单保留 1 安装、2 更新、3 配置管理、11 添加节点、12 迁移、13 卸载的约定。
- 错误字段就地重填，已填面板地址/密钥不要求重新输入；协议/内核/TLS 菜单可选 0 取消。
- 应用前保留新配置与修改前配置；运行失败后不自动覆盖新配置，提供编辑、重试、日志和主动恢复。
- 语法错误仅保留在草稿，不替换运行文件；运行错误可能使节点暂不可用，须修正或主动恢复。
- 草稿目录 0700、文件 0600；退出后可用主菜单 3 → 3 继续。
- `v2bx` 与 `v2bxss` 都可打开二开菜单；上游 `/usr/bin` 管理脚本保留。
  遇到不相关的 `/usr/local/bin/v2bx` 时保留并提示使用 `v2bxss`。
- 卸载和恢复包含属于二开的 `v2bx` 快捷入口，配置/程序升级回滚保护保留。
