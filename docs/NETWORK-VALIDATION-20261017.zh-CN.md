## 规则与面板

- 可选模板包含 11 个矿池域名、SMTP 直投端口 25、依赖内核识别的 BitTorrent 项。模板文件不会自动加载，不改变现有节点。
- 测试面板只在隐藏合成节点启用矿池域名和端口规则；HY2 不支持的 BitTorrent 项保持停用。已核对面板版本和节点应用版本一致。
- 列表按域名、IP/网段、端口、应用协议分类，支持启用状态和匹配类型筛选；筛选在分页前执行。
- 批量预览指出行号、不可见字符和不兼容的正文特征，保留已有规则的操作与状态。合法邮件域名正则不会因包含 SMTP 分组而被误判为正文特征。
- PHP 内存 SQLite 隔离回归为 42 项基础、64 项 HTTP 组合、115 项批量组合检查通过；这些是三个脚本的累计计数，不能相加当作互不重叠的用例。
- 本地浏览器合成接口回归 28 项通过；真实测试页面 8 项交互检查、本地规则只读抽屉与移动端 3 项检查通过，无页面脚本错误。

## 业务回归与边界

测试站真实登录、用户接口、无效注册请求校验、合成账户未支付订单创建/查询/取消的外部 HTTP 检查 8 项通过。业务内核回归 29 项通过，含模拟支付签名校验、重复回调、真实订单开通处理、流量聚合、额度/到期移除和流量重置；测试使用模拟网关、队列和 Redis，事务回滚，没有真实付款或商户回调验收。没有新建真实邮箱的正向注册测试。

13 个传输组合通过不代表所有客户端和应用协议嗅探均已验收。原生 HY2 没有应用协议识别；本批没有真实 BitTorrent 数据流的端到端识别验收。域名测试检查拒绝连接与命中回报，未断言在内核内部完全不发生 DNS 查询，也未测试加密请求里的 URL 路径或正文。

矿池清单含历史域名，不是持续更新的恶意网址情报；命中不证明恶意挖矿。端口 25 阻断也会影响合法邮件直投，不等于识别垃圾邮件。没有自动加入未经核验的恶意目标库；管理员可按已验证的域名、IP 或端口规则维护网络安全策略。

测试节点原运行服务保持运行，自动重启次数为 0。正式面板、原业务菜单和既有节点均未在本批更新。
