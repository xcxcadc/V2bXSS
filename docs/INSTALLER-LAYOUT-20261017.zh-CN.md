# 安装目录及管理入口修复验收

日期：2026-10-17。只涉及二开节点的安装、管理和迁移脚本，不修改节点协议、
面板、数据库、支付或用户鉴权业务代码。

## 统一后的路径

| 对象 | 路径 |
| --- | --- |
| 管理命令 | `/usr/local/bin/v2bxss`（快捷入口） |
| 管理脚本 | `/etc/v2bxss/v2bxss` |
| 配置 | `/etc/v2bxss/config.json` |
| 程序 | `/etc/v2bxss/current/v2bxss` |
| 服务 | `/etc/systemd/system/v2bxss.service` |
| 备份 | `/var/backups/v2bxss/` |

原版独立原位升级仍保留 `/etc/V2bX` 和原服务，不强制迁移；不与新装入口混用。

## 隔离回归

在远端 Linux/amd64 逐项执行，无本机编译：配置向导 8 项、菜单/日志 9 项、
固定提交安装入口 24 项（内含 bundle 的 13 项完整性检查）、原版升级 12 项。
另外验证管理器重复修复、缺失管理文件后的错误提示与恢复、高级新装也安装管理入口、
新版本启动失败回滚、旧目录迁移及显式回滚、旧二进制丢失后恢复、原来停止的服务
保持停止、服务切换失败自动回滚和自定义 unit 拒绝覆盖。

目录测试使用独立 mount namespace，将 `/etc`、`/opt`、`/var/backups`、
`/usr/local/bin` 四个目录挂载为临时 tmpfs；服务管理和程序为夹具。
没有把夹具测试冒充真实节点连接测试，也没有下载依赖或编译节点程序。

## 测试机实测

已在授权测试机恢复管理脚本，并将运行中的旧独立安装切换到新目录与服务。
旧 `/opt` 程序文件缺失，因此先备份运行中的可执行文件并恢复旧服务的重启路径，
才停止旧进程。切换后检查：

- `v2bxss` 能正常显示菜单，不再引用不存在的旧管理脚本；
- 新服务启用并运行，旧服务停止并禁用，避免重复对接；
- 迁移前后程序 SHA256 相同、UDP 监听地址/端口相同；
- 配置字节只替换旧私有目录前缀，其他字段不变；TLS 证书/私钥逐字节一致；
- 原配置、程序恢复副本、迁移备份和回滚脚本保留在测试机，不上传 GitHub。

迁移不升级原二进制版本；之后选择菜单 1 才更新二开代码。
本轮不重测所有 GUI 客户端、支付/真实订单或全部协议矩阵；协议测试范围另见
[多协议验收记录](PROTOCOL-VALIDATION-20261017.zh-CN.md)。正式服未操作。
